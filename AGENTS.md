# Effect

This repository uses the Effect TypeScript library, pinned through the workspace catalog.

Before writing Effect code, read `node_modules/effect/AGENTS.md` completely and follow its links when needed. If that root dependency is unavailable, the same installed guide is at `packages/runner/node_modules/effect/AGENTS.md`.

For APIs and concepts the guide does not cover, search `node_modules/effect/src`. Use the installed version rather than examples for another Effect release.
